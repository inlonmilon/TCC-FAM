Site de vendas de itens personalizados online, com catálogo de produtos, carrinho de compras e painel administrativo, desenvolvido como TCC.

---

## 🔹 Funcionalidades

- **Autenticação de usuários:** login e cadastro.  
- **Carrinho de compras:** adicionar, remover e visualizar produtos.  
- **Painel administrativo:**  
  - Gerenciar pedidos e status de entrega.  
  - Cadastrar e gerenciar produtos.  
  - Gerenciar usuários e definir administradores adicionais.  
- **Perfil do usuário:** acompanhar status dos pedidos e acessar o carrinho.  

---

## 🛠 Tecnologias Utilizadas

- **Front-end:** HTML, CSS, jQuery, AJAX  
- **Back-end:** PHP, Programação Orientada a Objetos (POO)  
- **Banco de Dados:** MySQL  
- **Design:** Figma  
- **Outros:** JSON  

---

## ⚡ Como Executar

O projeto roda **localmente**:

1. Instale um servidor local com suporte a PHP e MySQL (ex.: XAMPP, WAMP ou MAMP).  
2. Importe o banco de dados MySQL fornecido para criar as tabelas necessárias.  
3. Coloque os arquivos do projeto na pasta do servidor local (ex.: `htdocs` no XAMPP).  
4. Abra o navegador e acesse:  
´´´
http://localhost/tcc-fam-main/view/index.php
´´´
